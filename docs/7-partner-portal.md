# Partners and referrers

The [SolarMiner portal](https://portal.solarminer.app) is the central access point for partners. You can apply through the [partner application](https://portal.solarminer.app/en/apply). The form asks for a contact address and message, among other details, and lets you suggest a share. A requested share is not a promised rate; the operator reviews the application.

After approval and access to the portal, you will find your referral code and a shareable link in the referrer dashboard. Users select the code in their Node under `Mining`; the Node then displays the applicable fee allocation. The code must be valid and active. The portal manages the partner's share centrally; it cannot be changed from the referrer dashboard.

## Read the referrer dashboard

The dashboard shows Bitcoin hashrate from Braiins, shares, daily charts, assigned users, and known or estimated credits. Some views are **Bitcoin- or pool-specific**, not totals across every coin. A value can be incomplete if price or pool data is missing. A credit is an amount accrued at the pool, not an automatic payment by SolarMiner.

Partners can enter pool credentials for supported payout paths in their own profile: currently a Braiins/BTC API token and PRL and XMR wallet addresses. Existing values are displayed in masked form. Saving a wallet alone does not guarantee active fee routing or a credit; the pool and fee route for each coin must be configured and verified. For Monero in particular, partner accounting depends on available pool verification.

Enter access tokens only in the portal form; do not include them in support messages. Check revenue directly at the pool as well. If figures differ, tell the operator the coin, referral code, period, and affected pool worker, but never send API tokens or private wallet keys.

## For users of a referral code

Open your local Node, choose an active code from the catalog under `Mining` or enter one, and save it. The Node reports its code assignment to the portal independently of optional site telemetry. The public code catalog lists available active non-house codes; the Mining view then shows the exact allocation. See [data flows and consent](./8-data-privacy.md).
