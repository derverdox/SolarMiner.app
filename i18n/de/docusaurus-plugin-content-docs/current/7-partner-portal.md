# Partner und Referrer

Das [SolarMiner-Portal](https://portal.solarminer.app) ist der zentrale Zugang für Partner. Eine Bewerbung ist über die [Partner-Bewerbung](https://portal.solarminer.app/de/apply) möglich. Das Formular fragt unter anderem Kontaktadresse, Nachricht und optional gewünschte Beteiligung ab. Ein eingetragener Wunschwert ist noch keine zugesagte Kondition; die Bewerbung wird vom Betreiber geprüft.

Nach Freigabe und Zugang zum Portal findest du deinen Referral-Code und einen teilbaren Link im Referrer-Dashboard. Nutzer wählen den Code in ihrer Node unter `Mining`; die Node zeigt die dann geltende Gebührenaufteilung. Der Code muss dort gültig und aktiv sein. Das Portal verwaltet den Partner-Anteil zentral; er lässt sich im Referrer-Dashboard nicht selbst ändern.

## Das Referrer-Dashboard lesen

Das Dashboard zeigt Bitcoin-Hashrate über Braiins, Shares, Tagesverläufe, zugeordnete Nutzer und bekannte bzw. geschätzte Gutschriften. Einige Ansichten sind **Bitcoin- oder pool-spezifisch** und keine Summen über alle Coins. Wenn Kurs- oder Pooldaten fehlen, kann ein Wert unvollständig sein. Die Gutschrift ist eine im Pool entstehende Forderung bzw. Pool-Akkumulation, keine automatische Auszahlung durch SolarMiner.

Partner können im eigenen Profil Pool-Zugangsdaten für die unterstützten Auszahlungswege hinterlegen: derzeit einen Braiins/BTC-API-Token sowie PRL- und XMR-Wallet-Adressen. Vorhandene Werte werden maskiert angezeigt. Das Speichern einer Wallet allein garantiert noch kein aktives Fee-Routing oder eine Gutschrift; je Coin müssen Pool- und Gebührenroute eingerichtet und geprüft sein. Insbesondere für Monero hängt die Partner-Abrechnung von der verfügbaren Pool-Verifikation ab.

Gib Zugangstokens nur in der Portalmaske ein und teile sie nicht in Support-Nachrichten. Prüfe Einnahmen zusätzlich direkt beim Pool. Bei Abweichungen nenne dem Betreiber Coin, Referral-Code, Zeitraum und betroffenen Pool-Worker, aber keine API-Token oder privaten Wallet-Schlüssel.

## Für Nutzer eines Referral-Codes

Öffne die lokale Node, wähle unter `Mining` einen aktiven Code aus dem Katalog oder gib ihn ein und speichere ihn. Die Node meldet ihre Code-Zuordnung unabhängig von der freiwilligen Site-Telemetrie an das Portal. Die öffentliche Code-Liste zeigt verfügbare aktive Nicht-Haus-Codes; die genaue Aufteilung siehst du anschließend in der Mining-Ansicht. [Datenflüsse und Einwilligung](./8-data-privacy.md).
